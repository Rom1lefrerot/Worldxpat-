# WorldXpat - Site Web

Site one-page ultra épuré et professionnel pour WorldXpat, permettant aux expatriés à Dubaï de trouver les bons groupes WhatsApp.

## 🚀 Lancement

Le site est en HTML/CSS/JavaScript pur, aucune installation nécessaire.

### Option 1 : Ouvrir directement
Double-cliquez sur `index.html` dans votre navigateur.

### Option 2 : Serveur local (recommandé)
Pour éviter les problèmes de CORS et tester dans de meilleures conditions :

```bash
# Avec Python 3
python3 -m http.server 8000

# Avec Node.js (si vous avez npx)
npx serve .

# Avec PHP
php -S localhost:8000
```

Puis ouvrez `http://localhost:8000` dans votre navigateur.

## 📁 Structure

- `index.html` - Structure HTML complète
- `styles.css` - Tous les styles (design minimaliste, responsive)
- `script.js` - Logique JavaScript (filtres, animations, interactions)
